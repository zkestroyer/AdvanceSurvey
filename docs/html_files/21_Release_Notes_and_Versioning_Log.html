Release Notes & Versioning Log

This document serves as the master changelog for all builds (specifically Mobile Apps, but also applies to Web/APIs) released to the client or deployed to production. It ensures we maintain a strict historical record of exactly what features and bug fixes were delivered in which specific version.

Versioning Standard

We follow Semantic Versioning (SemVer): MAJOR.MINOR.PATCH (e.g., v1.2.4) - MAJOR: Breaking changes, entirely new UI, or massive overhauls. - MINOR: New features added in a backward-compatible manner. - PATCH: Bug fixes, hotfixes, or minor tweaks.
