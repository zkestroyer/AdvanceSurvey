3. Manual Security Checks (OWASP Top 10)

  • [ ] Injection (SQLi, NoSQLi): All user inputs are sanitized and parameterized queries are used.
  • [ ] Broken Authentication: Passwords are hashed (bcrypt/Argon2), JWT tokens are secure and have expiration.
  • [ ] Sensitive Data Exposure: TLS/SSL enforced everywhere. PII/Financial data is encrypted at rest.
  • [ ] XML External Entities (XXE): XML parsers configured to disable DTDs.
  • [ ] Broken Access Control: Role-Based Access Control (RBAC) verified. Users cannot access other users' data (IDOR prevention).
  • [ ] Security Misconfiguration: Default credentials changed, unnecessary ports closed, detailed error messages disabled in production.
  • [ ] Cross-Site Scripting (XSS): Inputs/Outputs properly escaped. Content Security Policy (CSP) headers active.
  • [ ] Insecure Deserialization: Serialized objects verified before processing.
  • [ ] Using Components with Known Vulnerabilities: All third-party libraries up to date.
  • [ ] Insufficient Logging & Monitoring: Important actions (login, data modification) are logged securely.
