Phase 9: Deployment SOP

CRITICAL RULE: Deployments must be zero-downtime where possible. Never overwrite production databases during a code deployment.

1. Target Environment Details

  • Live Server IP / Domain:
  • Server OS: (e.g., Ubuntu 22.04)
  • Web Server: (e.g., Nginx, Apache)

2. Pre-Deployment Checklist

  • [ ] UAT Sign-off completed (Phase 8).
  • [ ] Production database backed up.
  • [ ] .env file for production configured with correct keys (DB, SMTP, Stripe).
  • [ ] Debug mode / Development errors turned OFF.

3. Deployment Steps

Step-by-step commands or processes to deploy. 1. ssh user@live-server 2. cd /var/www/project 3. git pull origin main 4. npm install --production (or composer install --no-dev) 5. npm run build 6. pm2 restart app-name (or restart Nginx)

4. Post-Deployment Verification (Smoke Test)

  • [ ] SSL Certificate valid and HTTPS forcing active.
  • [ ] Homepage loads successfully.
  • [ ] Can log in with a test account.
  • [ ] Emails/Notifications are sending correctly.

5. Rollback Plan

If deployment fails, execute these steps immediately: 1. Revert to previous Git commit: git checkout HEAD^1 2. Restart services.
