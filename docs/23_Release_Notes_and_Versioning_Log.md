# Release Notes & Versioning Log

This document serves as the master changelog for all builds deployed to production.

## Versioning Standard
We follow Semantic Versioning (SemVer): `MAJOR.MINOR.PATCH` (e.g., `v1.2.4`)
- **MAJOR:** Breaking changes, entirely new UI.
- **MINOR:** New features added in a backward-compatible manner.
- **PATCH:** Bug fixes, hotfixes.
